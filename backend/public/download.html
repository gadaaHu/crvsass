A complete assessment platform built for CRVS field officers

📝
Pre & Post Assessments
Structured questionnaires aligned with Proclamation 1370/2017 and the digital CRVS system curriculum.
📊
Live Analytics Dashboard
Real-time analytics with performance bands, competency deltas, and certification pipeline tracking.
🏛️
Multi-Jurisdiction Cascade
Dynamic cascading selectors for Dire Dawa, Addis Ababa, Oromia, Amhara, and all Ethiopian regions with matching weredas and kebeles.
🌐
Bilingual UI
Full Amharic (አማርኛ) and English interface, switchable on-the-fly for every screen.

Local Room database stores all submissions; auto-syncs with the backend when connectivity is restored.

Manager Authorization Gate
Prevents examinees from accessing the Post-Test until unlocked by an authorized manager or admin.
